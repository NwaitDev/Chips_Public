\begin{lstlisting}[caption={Exemple de programme CHIPS pour la simulation d'un drone avec un contrôleur PID},label={lst:drone_pid}]
logical Drone(float u, float dt) init {
    float m = 0.2;
    float altitude = 0.;
    float altitude_max = 0.;
    float velocity = 0.;
    float prevError = 0.;
    float GRAVITY = 9.81;
    float KP = 0.29;
    float DRAG_COEFF = 0.8;
}then{
    float radian = ((2. * 3.14159265358979323846) / 60.);
    float K = 4. * KP * radian * radian;
    float Fp = K * u * u;
    float drag = DRAG_COEFF * velocity;
    float a = (Fp / m) - GRAVITY - (drag / m);
    velocity = velocity + a * dt;
    altitude = altitude + velocity * dt;
    if(altitude < 0.){
        altitude = 0.;
        velocity = 0.;
    }
    if(altitude_max < altitude){
        altitude_max = altitude;
    }else{
        altitude_max = altitude_max;
    }
} -> update(altitude)

logical PID(float target, float current, float dt) init {
    float prevError = 0.;
    float proportional = 0.;
    float integral = 0.;
    float derivative = 0.;
    float kp = 1.5;
    float ki = 0.6;
    float kd = 0.0;
    float minOutput = 0.0;
    float maxOutput = 15.0;
}then{
    float error = target - current;
    float p_out = kp * error;
    proportional = error;
    integral = integral + error * dt;
    float i_out = ki * integral;
    derivative = 0.;
    if(dt > 0.){
        derivative = (error - prevError) / dt;
    }
    float d_out = kd * derivative;
    float rawCorrection = p_out + i_out + d_out;
    float saturated = (float)(max((int)(minOutput), min((int)(rawCorrection), (int)(maxOutput))));
    prevError = error;
} -> correction(saturated)

system {
    PID ctrl;
    Drone drone;
    float dt = 0.1;
    float target = 5.0;
    ctrl.dt(dt);
    ctrl.target(target);
    ctrl.current(drone.update);
    drone.u(ctrl.correction);
    drone.dt(dt);
}

\section*{Résumé}

Ce rapport présente les travaux de développement et d'amélioration du compilateur pour le langage \textbf{CHIPS} 
(Control of Hierarchical Interconnected Programmable Systems), un langage dédié à la modélisation formelle de systèmes distribués complexes. 
Les objectifs principaux ont été de migrer le parseur historique vers ANTLR4 afin d'obtenir une architecture plus robuste et plus facilement 
extensible, d'adapter le générateur XMI au nouvel arbre syntaxique produit par ANTLR4, de développer une bibliothèque de filtres numériques 
comprenant des filtres passe-bas, passe-haut, Butterworth d'ordre 2 ainsi qu'un filtre médian, et d'implémenter plusieurs mécanismes d'anti-windup 
destinés aux contrôleurs PID, ainsi que d'évaluer expérimentalement les performances des différentes solutions proposées au moyen d'analyses 
temporelles, fréquentielles. Aussi de réaliser une chaîne de compilation complète pour le langage CHIPS intégrant l'ensemble de ces composants.

\paragraph{\textbf{Mots clés :}} CHIPS, C++, ANTLR4, XMI, méta-modèle, filtres, anti-windup, PID 
\vspace{1cm}

\section*{Abstract}
\selectlanguage{english}

This report presents the development and enhancement of the compiler for the CHIPS (Control of Hierarchical Interconnected Programmable Systems) 
language, a domain-specific language dedicated to the formal modeling of complex distributed systems. The main objectives were to migrate the legacy 
parser to ANTLR4 in order to obtain a more robust and easily extensible architecture, to adapt the XMI generator to the new abstract syntax tree 
produced by ANTLR4, to develop a library of digital filters including first-order low-pass and high-pass filters, a second-order Butterworth filter, 
and a median filter, and to implement several anti-windup mechanisms for PID controllers. In addition, the proposed solutions were experimentally 
evaluated through both time-domain and frequency-domain analyses. Finally, a complete compilation toolchain for the CHIPS language was developed, 
integrating all of these components.

\paragraph{\textbf{Keywords :}} CHIPS, C++, ANTLR4, XMI, meta-model, filters, anti-windup, PID
